    Waggo is a Kate‑style code editor for the browser, built on the Monaco Editor. Syntax highlighting is available for every language Monaco supports; HTML documents can be executed and previewed directly in the editor. Every keyboard shortcut is fully remappable from the Keyboard Shortcuts panel.
